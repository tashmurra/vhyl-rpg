# v1.4.0-alpha.1 — Expanded running and fatigue prerelease

This experimental source-library release adds an optional ordinary ground-running
activity. Games explicitly select it; existing Lite journeys retain their
behavior. It includes the previous freeform magic, GM interface, character/social
and Fright Check extensions.

## Included

- `RpgExpandedRunning` with sprinting and paced running, persistent partial
  intervals, interruption, pace changes and observational speed previews.
- Fatigue checks every 15 seconds of sprinting or 60 seconds of paced running,
  using the higher effective HT or Running score, with HT winning ties.
- A shared HT/Average Running skill definition and existing expanded training
  and point accounting.
- Sprint acceleration, fractional speeds and movement penalties strictly below
  one-third FP, using the profile's existing encumbrance and injury adjustments.
- Per-second ability-to-act checks, including when a long advance reaches zero
  FP, with actual elapsed time and ordered check receipts.
- Shared fatigue, overflow injury, health-condition clocks and quiet-rest
  recovery, with undo, rollback and cross-process save coverage.
- An authoring guide, generated API reference and explicit coverage ledger.

## Integration and limitations

Include the core, progression and Lite umbrella, then the expanded foundation,
expanded skills and `vhyl-rpg-expanded-running.t`, each once. Keep one persistent
running activity per character and call it inside an action or committed dialogue
transaction. See the [running guide](../expanded/running.md) for host time,
terrain, distance and rest integration.

Separate sprint and paced counters are a documented extension policy. This
release retains the existing Lite collapse approximation; conscious
incapacitation, critical-failure heart attacks and resuscitation are not added.
Enhanced Move, Fit/Very Fit, fatigue immunity, extra effort, racing contests and
automatic combat-movement integration remain outside this module.

Dependency revisions remain pinned in `dependencies.json`. Saves require the
exact compiled game; upgrading a game requires migration or a new game.

## Validation and packaging

The implementation passed the [PR #9 CI run](https://github.com/tashmurra/vhyl-rpg/actions/runs/40866725357),
including native checks on Linux, Windows and macOS and source/documentation
package checks. Local validation also passed 25 source programs, 38 Python/tool
tests, the full native suite and strict documentation checks. Running coverage
includes interval and FP boundaries, skill selection, speeds, exhaustion,
overflow checks, rest, batching equivalence, undo/rollback and persistence.
The complete Lite suite passed both without and with the extension included.

Compiler and native builds are not repeated for this release. Only `VERSION`
and these release notes differ from the validated implementation. The existing
CI artifacts were downloaded and verified against the merged implementation;
the source and offline documentation packages are generated once for the release
commit and checked against its exact tracked tree. Release provenance records
the metadata-only delta, validated revision, successful jobs and asset hashes.

Assets include source and offline HTML documentation archives, a release
manifest, `SHA256SUMS` and release provenance. This library has no standalone
executable; compile its sources into a game using the pinned dependencies.
