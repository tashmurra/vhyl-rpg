# v1.4.0 — Life magic balance and stable rules release

This stable source-library release includes the functionality from
[v1.4.0-alpha.1](v1.4.0-alpha.1.md) and realigns Life permissions with
`anniversary-2015`, printed pp. 516–517. Other domains and the host casting,
resistance, injury and resource mechanics keep their documented conversion rules.

## Life changes

- Self-healing moves from rank 3 to 2; healing other complex organisms moves from 4 to 3.
- Direct injury to complex organisms requires rank 3; simple organisms remain rank 2.
- Authored cosmetic self-alteration is available at rank 2; functional self-alteration remains 3.
- Simple-organism transformation moves from rank 5 to 3.
- Authored self-transformation into a form of similar size and mass moves from 5 to 4.
- Altering other complex bodies remains 4; transforming them remains 5.
- Creation remains rank 3 for familiar simple life, 5 for complex or wholly invented life, plus power 2.

See the [Life guide](../magic.md#life-rank-progression) for cosmetic and form
classifications, declaration invalidation and host responsibilities. Lower-rank
forms do not automatically confer special abilities. Permanent Pattern rewriting
is not added. Backlash/unstable injury exclusions, shared treatment limits,
healing amounts, severe-wound surcharges and instability remain in force.

## Integration and compatibility

All expanded and magic modules remain opt-in, with the existing coverage limits,
including deferred spirit-vessel construction. Stable packaging does not imply
complete implementation of the source rulebooks. Existing untagged
`reshape-life` and complex `transform-life` declarations retain conservative
requirements; authors opt into cosmetic and similar-form classifications.

Rank changes also affect derived casting skill and strain. Review authored
formulae, local rank limits and encounter balance. Dependency pins are unchanged.
Saves still require the exact compiled game; use a new game or an authored migration.

## Validation and release

Regression coverage exercises Life permission derivation, rank-gated healing
casts, blocked casts without injury/RNG changes, classification restrictions and
prepared-declaration invalidation, alongside the existing native suite.
Local validation passed 38 Python/tool tests, 25 source programs, strict
documentation generation (479 declarations), and the native regression suites
on Intel macOS with LLVM 22.1.8 and Rust 1.98.1.
The PR workflow validates Linux, Windows and macOS and produces source and offline
documentation packages. The release workflow reuses those validated packages on
merge/tag when the complete tracked tree matches; no additional manual build or
workflow dispatch is required. Tagging `v1.4.0` after merge publishes the stable
release through the existing workflow.
