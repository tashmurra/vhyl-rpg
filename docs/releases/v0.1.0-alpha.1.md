# v0.1.0-alpha.1 — Mundane prototype

The first vhyl-rpg pre-release adds character profiles and authored challenge
resolution for hybrid parser, structured-action and choice-based adventures.
It is intended for experimentation; API and save compatibility may change.

## Included

- Shared PC/NPC attributes, trained and default skills, and narrow trait modifiers.
- Ordinary three-die checks, opposed checks, automatic solutions, costly success,
  authored consequences, time/energy costs and persistent retry records.
- Optional exact success odds, skill/modifier explanations and recorded dice
  reports, controlled by author disclosure and player preferences.
- Undo, exception rollback and cross-process logical save restoration.
- A playable hybrid example, authoring/reporting guides and a searchable API reference.

Injury, recovery, advancement and supernatural abilities are future modules.

## Dependencies and packages

This release pins **vhyl v0.2.1** (`53dbf3b94bb12f269fc447c414bff09fc0b7e46d`)
and **Zebulon v0.1.2** (`089a6f1d2a55014d0e89bb78d35f82647fdcea61`).
They are separate dependencies; native compilation requires the compiler's
platform toolchain as described in the [development guide](../development.md).

The [GitHub pre-release](https://github.com/tashmurra/vhyl-rpg/releases/tag/v0.1.0-alpha.1)
provides a source package, an offline HTML documentation package, a manifest
recording the exact source revision and dependencies, and SHA-256 checksums.
The source library is included when compiling a game and has no standalone
library executable. Native example bundles are not distributed in these packages.

## Validation

The release workflow gates publication on Python tests, all three complete source
programs, native mechanics/reporting/host tests on Linux, Windows and macOS, and
a strict documentation build. Native tests cover retry rules, costs, outcome
boundaries, exact probability enumeration, disclosure, historical calculations,
undo, rollback and cross-process saves. Native Intel macOS behavior was also
verified locally on the prototype.

Browse the [online reference](https://tashmurra.github.io/vhyl-rpg/) or extract
and serve the offline documentation package to use its search locally.
