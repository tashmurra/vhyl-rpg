# v0.2.0-alpha.1 — Playable resilience and progression

This pre-release adds optional injury, recovery, short physical/social conflicts,
and milestone development to the existing mundane challenge layer. Core-only
games remain supported. Supernatural and inspiration mechanics remain future work.

## Playable resilience

- Shared PC/NPC bodies with injury, shock, stun, exhaustion, incapacitation and
  author-controlled lethality.
- Armor/wounding arithmetic, supply-limited treatment with a bounded healing
  budget, explicit quiet rest and recovery maneuvers.
- Social disposition and request permissions, preserving shared retry records.
- Short encounters with attack/defense/damage, escape, surrender and bounded
  stalemates. Story consequences can arrange rescue instead of stopping play.
- A hybrid gatehouse example with peaceful passage, wounds, treatment, an optional
  confrontation, earned points and development choices.

## Progression

- One-time milestone receipts, earned/unspent point banks and NPC support.
- Owned skill investment, new skill slots, attribute improvements, trait grants
  and authored limitation buy-offs.
- Fictional unlocks, explicit downtime, current affordability checks and related
  goal revisions. Ordinary repetition does not earn points or grant rerolls.
- Undo, rollback and cross-process saves for condition, supplies, conflict state,
  milestones, purchases and historical challenge reports.

## Build promotion

Successful PR validation and packages are reused after merge and tagging when
the complete tracked Git tree matches. Source and HTML archives, the build
manifest and checksums remain byte-for-byte unchanged. A small provenance file
binds the published tag/merge commit to the validated build commit and CI run.
Changed trees or unavailable evidence require fresh validation; corruption stops
promotion.

The release pins **vhyl v0.2.1** (`53dbf3b94bb12f269fc447c414bff09fc0b7e46d`)
and **Zebulon v0.1.2** (`089a6f1d2a55014d0e89bb78d35f82647fdcea61`).
Packages contain source and offline HTML documentation, not platform game binaries.
API and save compatibility remain experimental.
