# v1.5.0 — Optional authored injuries

This additive stable source-library release introduces authored injuries for
arms, hands, legs, feet and broad internal trauma. Functional injury persists
independently of the HP deficit: recovering HP does not automatically repair a
lasting fracture or restore a disabled limb.

## Injury module

Include `vhyl-rpg-injuries.t` after Lite to enable authored consequences.
It supplies injury records, disabled-side combat and movement restrictions,
optional duration assessment, timed recovery, physician care and surgery.
Mortal internal injuries reuse the existing incapacitation and survival checks;
surgical stabilization can leave a lasting internal injury.

Include `vhyl-rpg-injuries-magic.t` after both injuries and the magic umbrella for
explicit Life repair through normal casting. It follows the adopted Life ranks:
2 for self-healing and 3 for another complex organism. Ordinary HP healing and
functional repair remain distinct; permanent restoration needs an authored effect.

The [injury guide](../injuries.md) documents the API and adaptation policies,
including 30-day months, broad internal exertion restrictions, treatment limits,
healing scope, elapsed-time ownership and trusted host responsibilities.
Automatic hit locations, individual-organ simulation, location armor, bleeding,
prostheses and a full anatomical trait catalogue remain outside this module.

## Integration and compatibility

The modules remain explicit includes and are absent from existing umbrellas.
Lite's capability hooks preserve existing behavior when the injury module is not
included. The extension integrates with combat, exploration, running, health
clocks and Life casting, and adds source-derived API documentation.

Dependency pins are unchanged. Saves still identify the exact compiled game;
upgrades require a new game or an authored migration. This release does not
claim complete expanded combat or full source-rulebook coverage.

## Validation and release

Local validation passed 38 Python/tool tests, 26 source programs, strict
documentation generation (485 declarations), and the complete native regression
suite on macOS. Broad-category injury tests cover functional restrictions,
internal trauma and stabilization, duration assessment, physician/surgical
recovery, Life repair and permission gating, undo, exception rollback and
cross-process save/restore. No individual-organ simulation is tested or supplied.

The PR workflow validates Linux, Windows and macOS and builds source and offline
documentation packages. After this PR is merged, tagging the merged commit
`v1.5.0` publishes the stable release through the existing workflow. Matching
validated tracked trees reuse the original packages and validation evidence.
