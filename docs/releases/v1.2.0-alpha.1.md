# v1.2.0-alpha.1 — Fright Checks prerelease

This experimental source-library release adds `vhyl-rpg-expanded-fright.t`, an
optional Fright Check module adapted from the GURPS fear rules (full-2008,
B360–B361). It builds on the v1.1.0-alpha.1 character/social modules. Existing
include paths, event contracts and default behavior are unchanged: including the
module does nothing until an author calls `rpgFrightCheck`.

## Included

- Will-based Fright Checks with situation modifiers (the monster, numbers, bodies,
  darkness, isolation, distance, briefing and repeat exposure) and fear-related
  traits, capped at 13 (Rule of 14).
- The full failure table, from a moment's stun to fainting, panic, comas,
  catatonia, seizures, injury, fatigue and permanent attribute loss.
- Timed fright episodes driven by Lite's health clock through the new
  `RpgLiteProfile.conditionTime` hook, with a lingering −2 after recovery.
- Pending quirk, delusion and disadvantage acquisitions that the author resolves
  with `rpgFrightAcquire`, which checks point cost. Traits acquired in play are
  exempt from the creation quirk limit.
- Undo, exception rollback and cross-process save coverage.

Rules are emulated in original wording with page citations. Where the book leaves
a call to the GM, the module's ruling is listed in the
[Fright Checks guide](../expanded/fright.md). Lite combat does not yet restrict
panicked or retching characters, and the Horror supplement is not covered.

The release workflow now fetches the validated build commit by ID, so deleting a
merged PR branch no longer breaks package verification on `main`.

## Use in Bellwether

Pin the library to `v1.2.0-alpha.1`. Extract the source release asset, add its `lib`
directory to the compiler include paths, and include these modules in order:

```text
#include <vhyl.h>
#include <vhyl.t>
#include <vhyl-rpg.t>
#include <vhyl-rpg-progression.t>
#include <vhyl-rpg-lite.t>
#include <vhyl-rpg-expanded-character-social.t>
#include <vhyl-rpg-expanded-fright.t>
```

Use the dependency revisions in `dependencies.json`: vhyl v0.2.1 (`53dbf3b`)
and Zebulon v0.1.2 (`089a6f1`). Saves require the exact compiled game; rebuilding
Bellwether requires a new game unless its author provides migration.

## Validation and packages

The release gate runs the Python/tool tests, the source programs, native core/Lite,
character/social and fright regressions, strict documentation builds, package
content verification and checksums. Native CI covers Linux, Windows and macOS.
The tagged workflow publishes only after these checks pass, or after verified
reuse of an identical validated source tree.

Assets include source and offline HTML documentation archives, a build manifest,
`SHA256SUMS` and release provenance linking the tag to the validated build.
This source library has no standalone executable; compile it into Bellwether.
