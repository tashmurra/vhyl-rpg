# v1.3.0-alpha.1 — Freeform magic and GM interface prerelease

This experimental source-library release adds an opt-in freeform magic extension
and a provider-neutral interface for recorded GM rulings. Existing games can
continue using the core and Lite libraries without including either module.

## Included

- Nine magic domains with separate ranks and trained skills, typed operations,
  declared scope, casting modifiers, resistance, countering and critical results.
- Cooperative casting and extended rituals with bounded retries, progress,
  interruption, endurance and resource accounting.
- Reserve, strain, backlash, lasting complications, item construction and use,
  and persistent world, body, mind and spirit effects.
- A bounded GM question/reply protocol and Python host bridge. Authored rulings
  work without an inference service; future local-model or OS AI adapters can
  supply proposals while the game retains control of mechanical eligibility,
  dice, costs and state changes.
- A playable example, integration documentation, adopted conversion decisions,
  source audit and a coverage ledger covering all 45 domain/rank entries.

## Integration and limitations

Include the expanded character and skill prerequisites, `vhyl-rpg-gm.t`, then
`vhyl-rpg-magic.t`. Follow the initialization and world-clock requirements in
[the magic guide](../magic.md) and the [GM contract](../gm.md).
Games author their objects, properties, practices, observations, relationships
and narrative consequences, and integrate the typed world-operation adapters.
Spirit-vessel construction remains deferred. This release does not bundle a
concrete inference provider, flawed-item mechanics or backlash postponement.

Dependency revisions remain pinned in `dependencies.json`. Saves require the
exact compiled game; upgrading a game requires migration or a new game.

## Validation and packaging

The implementation was validated by the existing [PR #8 CI run](https://github.com/tashmurra/vhyl-rpg/actions/runs/40305086486),
including native checks on Linux, Windows and macOS and the source/documentation
package checks. Local validation also covered magic workflows, all 45 rank
entries, resistance boundaries and persistence, plus 38 Python/tool tests and
24 source programs.

For this release, compiler and native build tasks are not repeated. Only
`VERSION` and these release notes differ from the validated implementation;
the source and offline documentation packages are regenerated for the release
commit and checked against its exact tracked tree. The release provenance asset
records both revisions, the metadata-only delta and the original validation run.
Assets include source and offline HTML documentation archives, the release
manifest, provenance and `SHA256SUMS`. This library has no standalone executable.
