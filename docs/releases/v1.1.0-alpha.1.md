# v1.1.0-alpha.1 — Bellwether character and social prerelease

This experimental source-library release adds six optional character/social
modules, a focused umbrella and the playable Town Registry integration example.
Existing core/Lite include paths and event contracts are retained. New context,
cost and learning hooks default to existing behavior when expansions are absent.

## Included

- Expanded character accounting and purchased secondary characteristics.
- Authored skills, defaults, prerequisites, specialties, techniques and familiarity.
- Trait price specifications and occupational template composition and choices.
- Standing, reputation recognition, reactions, information delivery, trade terms
  and loyalty records.
- Parser, structured-action and dialogue integration with private NPC state,
  repeat protection, undo, exception rollback and cross-process save coverage.

This is a partial interim implementation. Full trait/skill catalogues, ancestry,
influence/contact procedures, expanded combat and campaign economics remain
outside this release. Trade tables assess terms without transferring inventory;
trait pricing does not supply supernatural effects. See the
[coverage ledger](../expanded/coverage.json) and [library catalogue](../libraries.md).

## Use in Bellwether

Pin the library to `v1.1.0-alpha.1`. Extract the source release asset, add its `lib`
directory to the compiler include paths, and include these modules in order:

```text
#include <vhyl.h>
#include <vhyl.t>
#include <vhyl-rpg.t>
#include <vhyl-rpg-progression.t>
#include <vhyl-rpg-lite.t>
#include <vhyl-rpg-expanded-character-social.t>
```

Use the dependency revisions in `dependencies.json`: vhyl v0.2.1 (`53dbf3b`)
and Zebulon v0.1.2 (`089a6f1`). Follow the
[Town Registry build and play instructions](../../examples/bellwether/README.md)
and [integration guide](../expanded/index.md). Campaign options remain opt-in.
Saves require the exact compiled game; rebuilding Bellwether requires a new game
unless its author provides migration.

## Validation and packages

The release gate runs all 32 Python/tool tests, all 18 source programs, native
core/Lite and character/social regressions, strict documentation builds, package
content verification and checksums. Native CI covers Linux, Windows and macOS.
The tagged workflow publishes only after these checks pass or verified reuse of
the identical validated PR source tree.

Assets include source and offline HTML documentation archives, a build manifest,
`SHA256SUMS` and release provenance linking the tag to the validated build.
This source library has no standalone executable; compile it into Bellwether.
