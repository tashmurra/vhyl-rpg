# Implementation decisions

These are conversion policies after the three source investigations, not new
claims about the published rules. Original terminology and the 32 accepted
comparison decisions remain in the [plan](../freeform-magic-plan.md).

| Plan item | Implemented decision |
| --- | --- |
| R1 | Living/sapient direct targets resist with Will, including unconscious targets; conscious aware consent may waive, possession may not. Indirect delivery uses physical defenses. |
| R2 | Keep casting, counter-reduced scope and capped resistance margins separate. Reuse original dice, cap at max(16, Will), and take the lesser capped margin/scope. Cooperating or extended contributions are individually capped, then summed and bounded by surviving scope. |
| R3 | Critical casting does not bypass defenses. Critical eligibility can remove range/duration requirements for typed operations, never declared mass or damage requirements. Natural failures remain failures even with positive arithmetic margin. |
| R4 | Counter declarations precede casting, resolve in stable host initiative order, and allow one contribution per defender per incoming cast. Concerted counter critical failure defeats that contribution. Countering interrupts the defender's own work. |
| R5 | No ordinary resistance-to-magic bonus. |
| R6 | Debit at final ordinary casting roll, retain costs after failed delivery, charge elapsed interrupted work only. Record guards before application, replay receipts without new charges, and disclose private facts only through authored reporting. |
| S1/H1 | Pounds, yards, HP, Fahrenheit differences; mass stored in hundredths of a pound. Nearby is two yards, vicinity fifteen yards within sight. Raw-zero mass/temperature rows take priority; minimum one applies only where specified. Omit legacy passive defense. |
| S2/S3 | One reserve balance; strain immediately displaces it without refund. Transfers are atomic, no mandatory receiving reroll. Portable portions use predeclared allocations and lose unused excess. Remote transfer keeps one-per-margin throughput. |
| S4 | Freeze complication eligibility and total cost at batch start; only temporary strain pays. |
| S5 | Sum successful raw margins; critical failure dominates; share summed strain to every participant; one overt discharge each. Apply ritual minimum one once to the combined progress. |
| S6 | Cumulative rounded half-cost rank restoration preserves skill/formula investment. All failed craft checks destroy the item; craft/effect/power order is stable. Failed final charging activation is retryable. |
| S7 | Spatial mass adds matter 3 or life 2/simple, 3/self, 4/other. Momentum redirection adds energy 4. Selective living decay adds the appropriate life rank. Selective matter-property removal adds matter 3 or 5 for extraordinary properties. Region creation uses spirits 4, matter 4, power 3 and ten reserve with an authored region declaration. |
| S8 | Owned reversible-layer cancellation, memory reversal, passage closure and power-4 disenchantment; no universal dispel. |
| H2 | Injury provenance and shared treatment records; backlash is never magically healed; active unstable injury blocks natural healing too. Strongest equivalent positive/negative layers preserve base traits. Permanent selected mental benefits are paid. |
| H3 | Explicit work/ritual lifecycle and an idempotent world clock. Endurance is checked at hour boundaries. Suspension affects tagged subjective timers. Acceleration changes action opportunities, not world casting frequency. Forward travel processes deadlines. |
| H4 | Provider-independent bounded declarations, stale reply rejection and explicit world facts. Local practice profiles contribute one +1/0/−1 modifier. |
| H5 | Stable source period IDs, pooled source supply, final item capacity equals delivered charging points on interruption/shortfall, and an authored currency factor. Game content supplies ownership, location and eligibility. |
| H6 | Authored links and disclosures, reversible memory layers, separate projection health, relationship-based spirit contact, barrier contests and persistent topology. A game consumes these through explicit adapters. |
| H7 | Local rank equality is allowed. Future observation uses authored possibilities, never future RNG. False perceptions are authored and tested once each. Internal duration: 0/failure year; 1 month; 2 week; 3–5 day; 6 hour; 7 minute; 8+ second. |

The source evidence is recorded in the [audit](../freeform-magic-source-audit.md)
and [permission matrix](../freeform-magic-permissions.md). The only deferred
external-book procedure is spirit-vessel construction. A larger pre-authored
formula catalogue, game-specific environments and an inference backend are not
included in the deterministic library.
