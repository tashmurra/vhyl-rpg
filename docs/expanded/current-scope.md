# Current completion scope

The active completion target is the full applicable reference coverage for:

- Health and hazards.
- Characters, traits, skills and templates.
- Social interactions.
- Equipment and exploration.

All nine modules remain partial. This target includes their catalogues, executable
procedures, concrete author contracts, minimal and combined examples, integration
and validation. Existing partial implementation or a generic callback does not
satisfy completion. Source ambiguities must remain explicit until resolved from
the supplied printings. See the [coverage ledger](coverage.json) and
[detailed inventory](inventory/index.md).

Work on standalone tactical movement, magic, vehicles and other areas outside
this scope is deferred except where needed to implement the selected modules
correctly. Existing committed work remains available with its documented limits.
The final delivery must list all areas still outstanding across the broader suite;
this scope change does not label those areas implemented or remove their inventory.

fixtures are not evidence of passing behavior. Completion requires the appropriate
source, native, documentation and packaging checks after implementation, along
with the required regression and persistence coverage. Keep the existing PR draft
